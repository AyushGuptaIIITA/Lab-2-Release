# Case Study T2: Rural Telemedicine & e-Prescription Platform
> **Course:** Advanced Software Engineering (M.Tech)  
> **Lab 2:** SDLC Model Selection as a Multi-Criteria Decision Process  

## Project Overview
This repository contains the multi-criteria decision analysis (MCDA) framework used to evaluate, score, and select the optimal Software Development Life Cycle (SDLC) model for 
**Case Study T2: Rural Telemedicine Appointment & e-Prescription Platform**. The evaluation addresses core domain constraints including low network bandwidth, strict medical data privacy requirements, sparse stakeholder availability, and zero defect tolerance for e-prescriptions.
